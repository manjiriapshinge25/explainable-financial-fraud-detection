# Dataset setup

The notebook expects the PaySim CSV named:

`PS_20174392719_1491204439457_log.csv`

The notebook currently sets `DATA_PATH = Path("../data/PS_20174392719_1491204439457_log.csv")`, so place the dataset in a `data` folder one level above the folder from which the notebook is run, or update `DATA_PATH` to the correct local path. Do not upload the raw multi-million-row CSV to GitHub.
